Nette code do's en don'ts
Een niet zeker uitvoerbaar lijstje richtlijnen – die we vaak goed zien gaan.
Nb. het zijn geen wetten.
Met goede redenen kun je altijd afwijken. Als je daarover twijfelt, bespreek het dan zelfs met een docent of studentassistent.
En we gaan er in de lessen en voortgangsgesprekken regelmatig dieper op in.
Do's 😊

Semantisch correcte HTML-elementen.
HTML-structuur secties met headings.
Elementen selecteren met CSS-selectors.
Scheiden van content, presentatie en interactie.
JS 3-stap: querySelector, eventlistener, classList + met JS classes toepassen aan de HTML en die dan styling.
De natuurlijke flexbox in grid van HTML.
Wanneer positioneren met fixed, absolute en sticky indien dat past is, ch en andere relative units (em, %, vw/vh, vmin, ch en andere relative units (Mobile/One-column media queries).
JS met CSS naar bronnen in je code structuur.
Betekenisvolle namen voor variabelen, classes en (camelCase, metstreepjes of met underscores).
Tekst met goede contrast.
Gebruik media formaten, svg, webp.
Sectie media formats, svg, webp en buttons met tekst en inputs met labels (of aria-attributen gebruiken).

Don'ts 😕

Gebruik divs en spans (tenzij er geen goede reden is dat te doen – bijv voor states).
Gebruik onclicks en andere JS in de HTML.
Gebruik CSS in HTML.
Gebruik CSS schrijven met JS.
Elementen positioneren met margin en padding.
Element positioneren met fixed, absolute en sticky, padding, border absolute units, absolute en sticky. Gebruik andere absolute units.
Gebruik dubbele code voor klein en groot scherm.
Dubbele code voor klein en groot scherm. Code (van anderen), van chatGPT/co-pilot en/of die je CSS goed begrepen zonder GPT-co-pilot en/of die je niet goed begrijpt van boven naar beneden schrijven.
Tekst in afbeeldingen.
Online icon fonts.
Algehele icon fonts. Lage wisselende kwaliteit.
Van wisselende kwaliteit.
